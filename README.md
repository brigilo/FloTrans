# FloTrans

Proyecto académico de gestión y administración de transporte.

## Descripción

FloTrans busca facilitar la gestión de la información relacionada con conductores,
vehículos, rutas y contratos dentro de una plataforma web.

## Tecnologías

- HTML
- JavaScript
- PHP
- MySQL
- XAMPP

## Funcionalidades actuales

- Inicio de sesión.
- Registro de usuarios.
- Gestión de conductores.
- Gestión de vehículos.
- Gestión de rutas.
- Dashboard.
- Gestión de contratos mediante la API.

Actualmente la interfaz principal desarrollada corresponde al rol Administrador.
Los roles Operador y Conductor pueden registrarse, pero sus interfaces específicas
se encuentran pendientes de implementación.

## Ejecución

1. Instalar XAMPP.
2. Iniciar Apache y MySQL.
3. Crear/importar la base de datos `flotrans`.
4. Colocar el proyecto en la carpeta `htdocs`.
5. Abrir en el navegador:

http://localhost/flotrans/

## Estado del proyecto

El proyecto se encuentra en desarrollo. Las funcionalidades pendientes hacen parte
del alcance previsto para futuras etapas.
